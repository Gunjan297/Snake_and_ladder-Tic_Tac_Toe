# Snake and Ladder & Tic-Tac-Toe - C++ Project

This is my first C++ project featuring two classic games: **Snake and Ladder** and **Tic-Tac-Toe**. The project is console-based and includes **Player vs Player** and **Player vs Computer** modes. It is designed to improve logic building and hands-on experience with C++ fundamentals.

---

## Built With

- C++, OOP
- Standard Library
- Command Line Interface (CLI)

---

## Features

### 🐍 Snake and Ladder
- Player vs Player and Player vs Computer options
- Random dice rolls using `rand()`
- Fixed snake and ladder positions
- Turn-based gameplay until a player reaches 100

### ❌ Tic-Tac-Toe
- Player vs Player and Player vs Computer modes
- 3x3 grid
- Win detection (row, column, diagonal)
